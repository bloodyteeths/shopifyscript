## 🔧 How to Use the System

### Quick Start

```bash
# 1. Run database migrations
cd backend/migrations
psql $DATABASE_URL < 008_website_content_extraction.sql
psql $DATABASE_URL < 008_competitor_intelligence.sql
psql $DATABASE_URL < 009_traffic_patterns.sql

# 2. Set environment variables
export SUPABASE_URL="your-supabase-url"
export SUPABASE_SERVICE_ROLE_KEY="your-key"
export GOOGLE_API_KEY="your-gemini-key"
export GA4_PROPERTY_ID="your-ga4-id"

# 3. Start the server (AI starts automatically)
cd backend
npm start

# 4. Run integration test
node test-autonomous-system.js tenant_123
```

### Monitor System Health

```bash
# Check overall health
curl http://localhost:3000/api/ai-automation/health

# View tenant status
curl http://localhost:3000/api/ai-automation/tenant/tenant_123

# Check data store
curl http://localhost:3000/api/data-store/health
```

### Scrape Website for Content

```javascript
// API endpoint (implement in server.js)
POST /api/website/scrape
{
  "tenant": "tenant_123",
  "url": "https://example-store.com"
}
```

### Generate Optimized Ads
